\# Expense Tracker API



A RESTful Expense Tracker API built with Python, Flask, SQLite, and JWT authentication.



\## Features



\- User registration

\- User login

\- JWT authentication

\- Password hashing

\- Add expenses

\- List expenses

\- Update expenses

\- Delete expenses

\- Filter by past week

\- Filter by past month

\- Filter by last 3 months

\- Custom date range filtering

\- Expense categories



\## Run



pip install -r requirements.txt



python app.py



\## API Endpoints



POST /register



POST /login



POST /expenses



GET /expenses



PUT /expenses/<id>



DELETE /expenses/<id>
